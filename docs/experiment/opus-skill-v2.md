# 🐺 狼人殺 — 智慧 AI 補位多人連線版

一款在自己電腦上跑起來就能玩的網頁版狼人殺：真人玩家不足的座位由 Google Gemini 驅動的 AI 玩家補上，AI 會發言、抬槓、查驗、下毒與投票。

適合想在區域網路裡跟三五好友開一局，或是單純想旁觀一整場 AI 對戰的人。專案沒有發佈到任何套件庫，使用方式就是把原始碼抓下來、填入自己的 Gemini API 金鑰、在本機啟動。

> [!IMPORTANT]
> 每一位 AI 玩家的每一次發言、投票與夜間行動都會呼叫一次 Google Gemini API。沒有可用的 API 金鑰，遊戲無法進行。

## 遊戲模式

首頁提供兩個分頁，共三種玩法：

| 模式 | 怎麼開始 | 你的身分 |
| --- | --- | --- |
| 單人模式 | 單人模式分頁選人數後按「開始遊戲」 | 你佔一個座位，其餘全部是 AI |
| 多人大廳 | 多人大廳分頁建立房間，把 4 碼房號給朋友，或直接從房間列表加入 | 每位進房的真人各佔一個座位，開局時剩餘座位由 AI 補滿 |
| 上帝模式 | 在上述任一分頁勾選「上帝模式」再開局 | 你不參戰，全場都是 AI，所有人的身分對你公開，房主可隨時暫停／繼續 |

房號是隨機產生的 4 碼大寫英數字（例如 `W7KF`）。房間只在遊戲尚未開始時可加入，暱稱在同一房間內不可重複。

## 事前準備

- Python 3（`backend/requirements.txt` 未鎖定版本，撰寫本文件時以 3.14 通過語法檢查）
- 一組 [Google Gemini API 金鑰](https://ai.google.dev/gemini-api/docs/api-key)
- 一個現代瀏覽器（前端使用原生 WebSocket，無需額外建置工具）

## 安裝與啟動

### 1. 安裝相依套件

```bash
pip install -r backend/requirements.txt
```

### 2. 填入 API 金鑰

打開 `backend/config.py`，把第一行的預設佔位字串換成你的金鑰：

```python
API_KEY = "你的-gemini-api-key"
```

> [!CAUTION]
> 金鑰是直接寫死在 `backend/config.py` 裡的，程式不會讀取環境變數，也不會讀取 `.env`（`.gitignore` 雖然忽略了 `.env`，但沒有任何程式碼在讀它）。`config.py` 本身**不在** `.gitignore` 中，因此把這個專案推上公開的 Git 儲存庫前，務必先確認金鑰沒有被一起提交。

### 3. 啟動伺服器

```bash
python backend/main.py
```

伺服器會以 Uvicorn 監聽 `0.0.0.0:8765`，同時提供 WebSocket 與前端靜態檔案。啟動後開啟瀏覽器：

```
http://localhost:8765
```

看到「🐺 狼人殺」設定畫面就代表成功了。想確認伺服器活著也可以直接打健康檢查端點：

```bash
curl http://localhost:8765/health
```

```json
{"status":"ok"}
```

同區網的朋友把 `localhost` 換成你的內網 IP（例如 `http://192.168.1.20:8765`）即可連進同一個大廳。

> [!NOTE]
> 連接埠 `8765` 出現在兩個地方：`backend/main.py` 的 `uvicorn.run(...)` 與 `frontend/js/websocket.js` 中組出 WebSocket 位址的那一行。只改其中一邊，前端會連不上後端。

## 遊戲流程與角色

一局由「夜晚 → 白天發言 → 投票」循環組成，直到其中一方獲勝：

1. **夜晚**：狼人選擇擊殺目標（狼人之間可以在夜裡打字互相討論，AI 狼也會回話）→ 預言家查驗一人 → 女巫決定是否使用解藥或毒藥。
2. **白天**：公布昨晚死亡名單，玩家依序發言，每位發言者可以指定下一位發言的人。
3. **投票**：所有存活玩家投票，得票最高者出局並留下遺言。

勝負判定：狼人全部出局則好人陣營獲勝；存活狼人數量大於或等於其他存活玩家數量時，狼人陣營獲勝。

### 角色配置

人數可選 6 至 12 人，職業分配固定如下（定義於 `backend/config.py` 的 `ROLE_DISTS`）：

| 總人數 | 🐺 狼人 | 👤 村民 | 🔮 預言家 | 🧪 女巫 |
| --- | --- | --- | --- | --- |
| 6 | 2 | 2 | 1 | 1 |
| 7 | 2 | 3 | 1 | 1 |
| 8 | 2 | 4 | 1 | 1 |
| 9 | 3 | 4 | 1 | 1 |
| 10 | 3 | 5 | 1 | 1 |
| 11 | 3 | 6 | 1 | 1 |
| 12 | 3 | 7 | 1 | 1 |

### AI 玩家的行為

- 每位 AI 開局時會隨機分配到一種說話風格（謹慎分析、直覺情緒、質問挑釁、沉穩高冷、跟風附和、激進帶風向、摸魚打太極），提示詞會要求它用口語與遊戲黑話發言，而不是寫分析報告。
- AI 只看得到自己該看到的資訊：狼人知道同伴、預言家記得自己的查驗結果、女巫知道藥水狀態。
- 真人玩家在輪到自己時有 **60 秒**可以操作，逾時系統會代打：發言送出「我還在觀察...」、投票隨機投給一名存活玩家、女巫則視為不用藥。
- 真人玩家中途斷線時，該座位會即時交給 AI 接管，遊戲不會中斷。

## 設定

所有可調參數集中在 `backend/config.py`：

| 參數 | 預設值 | 用途 |
| --- | --- | --- |
| `API_KEY` | `"API"`（佔位字串，必須替換） | Google Gemini API 金鑰 |
| `PRIMARY_MODEL` | `"gemma-4-26b-a4b-it"` | 主要使用的模型 |
| `FALLBACK_MODEL` | `"gemini-3.1-flash-lite"` | 主模型重試失敗後改用的備援模型 |
| `LLM_TIMEOUT` | `60` | 單次模型呼叫的逾時秒數 |
| `LLM_MAX_RETRIES` | `5` | 單一模型的最大重試次數 |
| `MIN_PLAYERS` / `MAX_PLAYERS` | `6` / `12` | 允許的總人數範圍 |
| `ROLE_DISTS` | 見上表 | 各人數對應的職業分配 |
| `ROLE_NAMES` | — | 職業的中文顯示名稱 |

模型呼叫失敗時的處理順序：遇到 429（額度超限）或 500（伺服器錯誤）會退避重試，其他錯誤直接切換到備援模型；兩個模型都失敗時，該名 AI 會回傳一句預設台詞（例如「我保持沉默。」），遊戲繼續進行。

> [!TIP]
> 兩個模型都要能被你的金鑰存取。若你的帳號沒有 `PRIMARY_MODEL` 的權限，整局會一路重試到備援模型，開局速度會明顯變慢——直接把兩個欄位都換成你確定可用的模型名稱即可。

## 專案結構

```
backend/
  main.py            FastAPI 進入點：WebSocket 訊息路由、靜態檔案服務、健康檢查
  game.py            房間管理（Room / LobbyManager）與遊戲引擎（GameEngine）
  llm.py             Gemini 呼叫、重試與備援邏輯，以及各角色的提示詞組裝
  config.py          金鑰、模型、人數與職業配置
  requirements.txt   Python 相依套件
frontend/
  index.html         大廳、房間等待、遊戲三個頁面的版面
  js/websocket.js    WebSocket 連線與訊息封裝
  js/game.js         遊戲畫面渲染與各階段互動
  js/app.js          大廳與頁面切換
  css/style.css      樣式
```

後端只有三個對外入口：`GET /health` 健康檢查、`WS /ws` 全部遊戲訊息、以及 `GET /{path}` 回傳 `frontend/` 底下的靜態檔案（找不到檔案時回落到 `index.html`）。

## 已知限制與風險

> [!WARNING]
> 這個伺服器沒有任何身分驗證機制，並且預設綁定 `0.0.0.0`（對外開放所有網路介面）。任何連得到這個連接埠的人都能列出所有等待中的房間、看到房號並直接加入。請只在信任的區域網路中使用，不要直接暴露到公開網際網路。

其他在採用前值得知道的事：

- **狀態全部存在記憶體**：房間與對局資料放在 Python 行程的變數裡，伺服器重啟後全部消失，也無法多行程或多機器水平擴充。
- **斷線無法回歸**：斷線的座位交給 AI 之後，原本的玩家重新連線也拿不回來，只能開新局。
- **成本與速度取決於模型**：AI 的每個動作都是一次 API 呼叫，人數越多、天數越長，呼叫次數越多。免費額度用完時會出現 429 退避重試，表現為遊戲節奏變慢。
- **上帝模式固定為 AI 對戰**：勾選上帝模式後你只能旁觀，無法參戰。
- **沒有自動化測試**：儲存庫中沒有測試檔案與 CI 設定，修改後請自行開一局驗證。
- **介面僅有繁體中文**：前端文案與 AI 提示詞都是中文，未提供多語系切換。
